# PDF to Markdown Converter (pdf-to-md)

Сервис для конвертации PDF, веб-страниц и Swagger-документов в чистый Markdown. 
Использует мультимодальные LLM через OpenRouter для распознавания таблиц и сложной верстки, 
а также умеет переходить по ссылкам внутри документа для обогащения контекста.

## Возможности
- **Приём PDF-файлов**: Загрузка через `multipart/form-data`.
- **Приём ссылок**: Конвертация по прямой ссылке на PDF, YAML (Swagger) или веб-страницу (HTML).
- **Link Resolution**: Автоматически переходит по ссылкам (до 5 штук), извлекает текст и дописывает его 
- в конец MD-файла. Это помогает ИИ-генератору тестов находить ответы на вопросы, если они спрятаны 
- в связанных документах.
- **Сохранение**: Все MD-файлы складываются в папку `../data/inbox`.

## Требования
- Java 21
- Maven 3.8+
- API-ключ OpenRouter.
